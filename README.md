### What I'm working on

- **SkySigner** — experimenting with Nostr signing, NIP-07, NIP-46 and client compatibility
- **NostrStone** — a Nostr-based client for sharing and discovering stones and minerals
- **BlockWave Radio** — monitoring mining pools, blocks, wallets and mining activity
- **Localhost Radar** — discovering and monitoring services running on localhost
- **CPU Miner Lab** — experimenting with CPU mining algorithms, pools and custom mining engines
